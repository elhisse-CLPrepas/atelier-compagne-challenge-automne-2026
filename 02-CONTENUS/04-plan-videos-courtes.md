# Plan de vidéos courtes

## Structure commune

1. Problème en trois secondes.
2. Explication ou démonstration.
3. Preuve visuelle.
4. CTA unique.

## Vidéo 1 — Pourquoi le Challenge existe

Durée : 60 secondes.

Script :

> Beaucoup de personnes utilisent l’IA. Peu savent transformer une idée en production qu’elles peuvent expliquer, contrôler et présenter. J’ai créé le Challenge 100 Jours pour installer cette capacité par la pratique. Pendant 14 semaines vous produisez des livrables et vous construisez un portfolio. La relance Automne 2026 commence le 25 septembre. Demandez le programme.

## Vidéo 2 — Démonstration d’une preuve

Durée : 45 secondes.

Montrer une page du portfolio. Expliquer : besoin, méthode, contrôle et résultat.

## Vidéo 3 — Un besoin métier

Durée : 45 secondes.

Choisir un public. Montrer une tâche difficile. Présenter une production possible sans promettre un résultat automatique.

## Vidéo 4 — La méthode LN-IA

Durée : 60 secondes.

```text
Idée → cadrage → prompt → production → contrôle → correction → preuve
```

## Vidéo 5 — Témoignage candidat

Durée : 30 à 60 secondes.

Questions :

- Quel était votre point de départ ?
- Qu’avez-vous produit ?
- Que savez-vous refaire aujourd’hui ?

## Vidéo 6 — GitHub sans jargon

Durée : 75 secondes.

Expliquer que GitHub sert à conserver les versions, organiser la review et montrer les preuves.

## Vidéo 7 — Dernier appel

Durée : 30 secondes.

Face caméra. Date, public, résultat, CTA. Aucun montage complexe.

## Contrôle qualité

- Son compréhensible.
- Sous-titres.
- Premier plan lisible.
- Aucun écran contenant une donnée personnelle.
- Lien placé dans le texte accompagnant la vidéo.
