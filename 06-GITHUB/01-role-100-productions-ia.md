# Rôle du projet « 100 Productions IA utiles et vérifiées »

## Ce que le projet apporte à la campagne

Le dépôt public peut jouer quatre rôles.

### 1. Preuve collective

Il montre que LN-IA ne se limite pas à enseigner des outils. La communauté produit, documente, relit et publie.

### 2. Aimant à prospects

Une personne peut découvrir le Challenge à travers un besoin réel : enseigner, organiser un projet, communiquer, produire un document ou résoudre un problème numérique.

### 3. Moteur de contenus

Chaque production validée peut générer :

- une affiche ;
- une vidéo courte ;
- un post métier ;
- une démonstration de webinaire ;
- une preuve dans le portfolio.

### 4. Atelier GitHub

Le projet rend visibles les Issues, branches, Pull Requests, reviews et décisions humaines.

## Ce que le projet ne doit pas faire

- Remplacer la page d’offre.
- Mélanger contribution gratuite et inscription payante.
- Promettre qu’une idée sera automatiquement publiée.
- Présenter une production non relue comme « vérifiée ».
- Exposer des données privées ou des fichiers internes.

## Message simple pour les prospects

> Pendant le Challenge vous ne restez pas seul avec des exercices. Vous pouvez contribuer à un projet collectif. Chaque production part d’un besoin réel. Elle est documentée, relue et publiée seulement après validation humaine.

## Parcours à expliquer

```text
Besoin réel
→ Issue structurée
→ production guidée
→ contrôle du contributeur
→ Pull Request
→ review humaine
→ corrections
→ publication
→ preuve dans le portfolio
```

## Usage dans la campagne

| Semaine | Contenu recommandé |
|---|---|
| 1 | expliquer « utile et vérifiée » |
| 2 | montrer une Issue et une fiche de production |
| 3 | démontrer une review et une correction |
| 4 | inviter les candidats à proposer un besoin réel |

## Positionnement

La promesse principale reste l’autonomie de production.

Le projet « 100 Productions IA » renforce cette promesse par une expérience collective, une méthode de contrôle et une preuve publique.
