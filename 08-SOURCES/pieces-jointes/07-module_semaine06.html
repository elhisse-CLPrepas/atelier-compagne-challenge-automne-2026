Concepts clés & erreurs à éviter

Erreurs de déploiement

  • Lancer sans champions : Pas de relais terrain, adoption lente.
  • Ignorer la communication : Les équipes ne savent pas pourquoi ni comment.
  • Oublier le support : Pas de réponse aux questions, frustration.
  • Déployer trop large d'un coup : Risque de saturation et d'incidents.
  • Négliger les rituels : Pas de suivi, pas d'ajustements.

Erreurs de mesure

  • Mesurer trop de choses : Perte de focus, données inexploitables.
  • Pas de mesure "avant" : Impossible de calculer un gain.
  • KPI non actionnables : Mesures qui n'informent pas les décisions.
  • Oublier la qualité : Se concentrer uniquement sur le temps gagné.
  • Ne pas documenter les preuves : ROI non vérifiable.

Prompts de vérification

Utilisez ces prompts pour auditer vos livrables.

Prompt "CAPSTONE AUDIT"

Détecte les trous : preuves, risques, données interdites.

En tant qu'auditeur interne, analyse le livrable suivant : [COLLER LE LIVRABLE]. Identifie : 1) Les preuves de mesure manquantes (avant/après), 2) Les risques non couverts (sécurité, conformité, continuité), 3) Les potentielles utilisations de données interdites (liste : {DONNEES_INTERDITES}). Format de sortie : tableau avec ligne, problème, criticité (élevée/moyenne/faible), recommandation. Règle : validation humaine obligatoire pour chaque problème identifié.
Prompt "REPRISE"

Améliore plan/ROI/playbook.

En tant qu'expert en déploiement IA, analyse et améliore le document suivant : [COLLER LE DOCUMENT]. Focus : 1) Renforcer les mesures de preuve (KPI concrets), 2) Clarifier les rôles (RACI), 3) Ajouter des contrôles vérifiables pour la sécurité et la qualité. Format de sortie : version améliorée du document avec changements surlignés. Règle : ne pas inventer de données ou d'exemples fictifs, utiliser uniquement le contexte fourni.
