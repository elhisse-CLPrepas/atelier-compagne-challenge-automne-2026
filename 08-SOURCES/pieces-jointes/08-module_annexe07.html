Objectifs de ce pack

Standardiser

Fournir des formats uniques pour tous les projets IA, garantissant cohérence et qualité.

Sécuriser

Intégrer la gouvernance minimale : validation, traçabilité, escalade, protection des données.

Opérationnaliser

Rendre l'IA actionnable au quotidien avec des templates courts, vérifiables, réutilisables.

Structurer un prompt efficace en 6 blocs : Rôle, Objectif, Contexte, Données, Contraintes, Format de sortie.

1) RÔLE Tu es [spécifier le rôle, ex: expert en communication marketing]. 2) OBJECTIF [Quel est le but concret de la tâche? Ex: Rédiger un email de relance client pour un produit spécifique.] 3) CONTEXTE [Informations sur la situation, l'audience, le ton, les enjeux. Ex: L'entreprise vend un logiciel B2B, le client a téléchargé un livre blanc mais n'a pas donné suite.] 4) DONNÉES (fournies) [Les données que vous fournissez à l'IA. Ex: Nom du produit: "SyncPro", avantages clés: automatisation, intégration, prix à mentionner: 99€/mois.] 5) CONTRAINTES [Les limites à respecter. Ex: Ne pas utiliser de jargon technique, respecter le ton professionnel mais amical, ne pas dépasser 150 mots, éviter les données sensibles.] 6) FORMAT DE SORTIE [Préciser le format attendu. Ex: Un paragraphe d'introduction, une liste à puces de 3 avantages, un appel à action clair.]

Que faire en cas de doute, d'erreur ou d'incident avec l'IA ?

PROCÉDURE D'ESCALADE IA 1. STOPPER - Arrêter immédiatement l'utilisation de l'outil IA pour la tâche en cours. - Ne pas diffuser, partager ou sauvegarder le résultat suspect. 2. RETIRER LES DONNÉES SENSIBLES - Si des données sensibles ont été saisies, les retirer de l'outil IA si possible. - Signaler l'incident au RSSI/DPO si une fuite est suspectée. 3. TRANSFÉRER AU VALIDATEUR - Contacter le validateur désigné : [À COMPLÉTER] - Fournir : le prompt utilisé, le résultat obtenu, le contexte, les données fournies (anonymisées). 4. DÉCISION Le validateur décide (sous 24h) : - Corriger : reformuler le prompt, ajuster les données. - Reformuler : demander une nouvelle version avec contraintes renforcées. - Abandonner : arrêter l'usage IA pour cette tâche, trouver une alternative. 5. TRACER LA DÉCISION - Documenter l'incident et la décision dans le journal de décisions : [À COMPLÉTER] - Mettre à jour le registre des risques si nécessaire. Règles d'usage rapide

  • Toujours utiliser un prompt structuré (6 blocs).
  • Vérifier la sortie avec la checklist qualité avant diffusion.
  • Pour tout document sensible/externe, validation humaine obligatoire.
  • En cas de doute : stopper, retirer données sensibles, escalader.
  • Documenter les décisions importantes dans le journal de décisions.
