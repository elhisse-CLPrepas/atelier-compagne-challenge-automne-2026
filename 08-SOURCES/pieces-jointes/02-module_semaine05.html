3) Concepts clés & erreurs

Structure atelier • erreurs d'animation • résistances
Structure d'un atelier (modèle stable)
  1. Objectif mesurable - Livrable + barème + seuil
  2. Démonstration courte - 3 minutes max, 1 exemple
  3. Pratique guidée - Binômes, template imposé
  4. Pratique autonome - Cas proche réel, durcissement
  5. Débrief - Ce qui marche/ne marche pas, prochain test
Règle d'or
Chaque étape doit produire une preuve observable et évaluable
Erreurs fréquentes d'animation

Symptôme : "On va comprendre / découvrir / explorer"
Correction : Écrire un livrable + un barème + un seuil de réussite

Symptôme : 20 minutes de démonstration passive
Correction : 3 minutes maximum, puis passage immédiat à la pratique

Symptôme : "Faites un prompt propre"
Correction : Imposer un format de sortie (titre, étapes, critères, exemple)

Symptôme : Note "au feeling" ou subjective
Correction : Grille explicite (compréhension, méthode, qualité, validation, traçabilité)
Gestion des résistances en formation
Peur / Anxiété
réponse
Phrase type
"Vous ne risquez rien. On teste sur un cas fictif. On mesure. On ajuste."
Action concrète
Réduire le périmètre • Donner un template • Valider une première sortie en 3 minutes
Scepticisme
réponse
Phrase type
"On ne croit pas. On compare avant/après sur un même livrable."
Action concrète
Définir un test simple • Chronométrer • Comparer qualité • Garder uniquement ce qui améliore
Surconfiance
réponse
Phrase type
"Parfait. Montrez une preuve. Ensuite on durcit les critères."
Action concrète
Ajouter des contraintes • Noter avec la grille • Exiger reproductibilité + traçabilité
GESTION DES RÉSISTANCES - PHRASES & ACTIONS

1. PEUR / ANXIÉTÉ
Phrase : "Vous ne risquez rien. On teste sur un cas fictif. On mesure. On ajuste."
Action : réduire le périmètre, fournir un template, valider une première sortie en 3 minutes.

2. SCEPTICISME
Phrase : "On ne croit pas. On compare avant/après sur un même livrable."
Action : test simple, chrono, comparaison qualité, garder uniquement ce qui améliore.

3. SURCONFIANCE
Phrase : "Parfait. Montrez une preuve. Ensuite on durcit les critères."
Action : contraintes plus dures, notation grille, exigence reproductibilité + traçabilité.

ÉVALUATION - 12 QUESTIONS

QCM (8 questions)
1. Objectif mesurable : quel élément est obligatoire ?
2. Démonstration : durée recommandée en atelier ?
3. Consigne : comment réduire l'ambiguïté ?
4. Critères : quel type est le plus testable ?
5. Hétérogénéité : quelle stratégie est correcte ?
6. Traçabilité : que doit-on noter obligatoirement ?
7. Validation humaine : quand l'exiger ?
8. Qualité sortie : quel contrôle appliquer ?

CAS COURTS (4 questions)
9. Objectif flou : réécrire en objectif mesurable + KPI
10. Démo trop longue : re-séquencer 90 minutes
11. Critères absents : écrire une grille simple sur 20
12. Résistance sceptique : définir un test avant/après

8) Évaluation & corrigés

QCM + Cas • Barèmes • Corrigés types
Corrigé type (extrait)

1) Livrable observable + barème + seuil
2) 3 minutes maximum
3) Imposer un format de sortie + exemple attendu/non attendu
4) Critères testables (oui/non ou points)
5) Template commun + durcissement progressif
6) Hypothèses + sources + limites
7) Pour tout document sensible ou communication externe
8) Vérification sur critères + revue par pair

Chaque cas se corrige avec la grille standard :
• Objectif mesurable présent
• Timeline réaliste (90 min)
• Consignes sans ambiguïté
• Critères testables
• Corrigé aligné
• Traçabilité mentionnée

RH (tri CV) : Données sensibles interdites + validation humaine déclenchée
Finance (synthèse) : Faits/écarts/actions/risques clairement séparés
Support IT (KB) : Diagnostic étape par étape + conditions d'escalade 
CORRIGÉ TYPE (EXTRAIT)

QCM - RÉPONSES
1. Élément obligatoire : livrable observable + barème + seuil
2. Durée démo : 3 minutes maximum
3. Réduire ambiguïté : imposer un format de sortie + exemple attendu/non attendu
4. Critères testables : oui/non ou points attribuables
5. Hétérogénéité : template commun + contraintes progressives
6. Traçabilité : hypothèses + sources + limites obligatoires
7. Validation humaine : documents sensibles ou communication externe
8. Contrôle qualité : revue par pair + test sur critères définis

CAS - PRINCIPES
• Un cas = une application de la grille
• Exiger : objectif mesurable, timeline, consignes claires, critères testables, corrigé, traçabilité
• Notation proportionnelle au respect des consignes

Prompts Assurance Qualité
PROMPT 1 — VÉRIFICATION QUALITÉ
Contexte : Formation entreprise. Module interne 90 minutes.
Tâche : Détecter tout flou et toute absence de critères testables.
Contraintes : Zéro invention. Si manque : [À COMPLÉTER].
Sortie imposée :
1. Liste des phrases floues (copier-coller exact)
2. Remplacement concret proposé pour chaque phrase
3. Critères manquants (liste)
4. Critères testables proposés (format points / oui-non)
5. Corrigés manquants (liste)
6. Risques d'animation identifiés
7. Score qualité /100 + actions prioritaires (max 3)

PROMPT 2 — REPRISE AMÉLIORATION
Contexte : Le module est jugé "trop vague" par les testeurs.
Tâche : Réécrire uniquement les consignes, critères et barèmes pour les rendre testables.
Contraintes : Conserver la structure et le contenu. Ne pas ajouter de nouveaux thèmes.
Sortie imposée :
• Version réécrite (consignes + critères + barèmes)
• Tableau comparatif "Avant → Après" (3 exemples)
• Justification pédagogique pour chaque changement
