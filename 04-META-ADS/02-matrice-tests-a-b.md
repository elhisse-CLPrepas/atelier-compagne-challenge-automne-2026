# Matrice de tests A/B

## Principe

Tester une variable à la fois. Garder la même audience, le même budget et la même période pour comparer deux créations.

| Test | Version A | Version B | Résultat à mesurer |
|---|---|---|---|
| Promesse | apprendre par la pratique | produire un portfolio de preuves | leads qualifiés |
| Angle | problème métier | résultat concret | leads qualifiés |
| Preuve | portfolio | témoignage | entretiens |
| Format | vidéo face caméra | affiche | coût par lead qualifié |
| CTA | demander le programme | réserver un échange | entretiens réalisés |
| Destination | formulaire instantané | WhatsApp | inscriptions confirmées |

## Nommage

```text
AUT26_SEG-A_PREUVE_VIDEO_CTA-PROGRAMME_V1
AUT26_SEG-B_PROBLEME_AFFICHE_CTA-ENTRETIEN_V1
```

## Journal de décision

Pour chaque test noter :

- hypothèse ;
- dates ;
- budget ;
- audience ;
- création ;
- résultats ;
- qualité des conversations ;
- décision : arrêter, corriger, poursuivre ou amplifier.

## Décision après test

Ne pas choisir la création qui obtient seulement le plus de clics.

Choisir celle qui produit le plus de prospects qualifiés et d’inscriptions à coût acceptable.
